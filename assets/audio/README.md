# Audio samples

Drop finished files in this folder using the exact names below — the
"Listen" section on the site (driven by [`tracks-data.js`](../../tracks-data.js))
picks them up automatically, no code changes needed. Any file not present
yet shows as "Sample coming soon" on the site.

MP3 recommended (widest browser/mobile support).
